## 修复：右侧引号图标不显示

- 症状：用户反馈 `<i class="icon icon-quotes-right">` 没有渲染
- 原因：重构时把图标绝对定位的 `top: 0` / `bottom: 0` 锚点丢了（原来 jQuery 动画把 bottom 从 -10px 推到 0），改成纯 transform 动画后绝对定位元素回到“静态位置”，结束图标被 1px 底线元素遮挡/容器 overflow:hidden 裁掉
- 修复：main.css 加回 `.quote-icon-start { left:0; top:0 }`、`.quote-icon-end { right:0; bottom:0 }`，保持 keyframes 用 translateY 产生滑入效果（最终静止位置 = 旧的 jQuery 动画结束位置）
